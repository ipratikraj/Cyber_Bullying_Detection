About This Project

This project was developed by Pratik Raj, MCA student at CUSAT, as a mini project to detect cyberbullying content using Machine Learning and NLP (Natural Language Processing) techniques.The system analyses text messages and predicts whether the content is harmful or non-harmful.

How It Works

The system processes text through a classic NLP pipeline:

1
Input Text
2
Clean & Normalise
3
TF-IDF Vectors
4
Logistic Regression
5
Prediction

Text cleaning removes URLs and punctuation. TF-IDF (Term Frequency – Inverse Document Frequency) converts words into numerical features. The Logistic Regression classifier then predicts whether the message is cyberbullying or not, along with a confidence score.

Tech Stack

Python 3 Flask scikit-learn TF-IDF Vectorizer Logistic Regression joblib HTML/CSS/JS

Model Performance

The model was trained on a labelled dataset of bullying and non-bullying messages and achieves over 91% accuracy on the test set. Precision and recall are balanced across both classes.

For a production system, you would train on a much larger dataset (e.g. the Kaggle Cyberbullying Classification dataset) to improve generalisation.

Disclaimer

This project is built for educational and research purposes. The model may make mistakes — no AI classifier is perfect. Always use human judgement alongside automated tools when dealing with real-world moderation.
